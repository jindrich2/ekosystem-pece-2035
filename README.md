# Udržitelný ekosystém péče 2035

Web k workshopům **CARE 2035** (KISK MU, Kampus Hybernská, říjen 2026). Shrnuje výchozí stav neformální péče v Česku a šest designových výzev k roku 2035.

## Obsah

- **Mapa kritických bariér a rizik** – čtyři pilíře s podstránkami podle plakátů A0:
  - A · Demografický a kapacitní kolaps
  - B · Socioekonomická zranitelnost neformálních pečujících
  - C · Finanční a legislativní brzdy
  - D · Rozdrobené obce, reforma společenství obcí
- **Designové výzvy pro neformální péči k roku 2035** (V1–V6)
- Sekce **Co říká obor** (časopis Sociální služby, APSS ČR) a **Z krajských střednědobých plánů rozvoje sociálních služeb**

Každý pilíř má vlastní barvu podle design systému CARE 2035 (A modrá, B růžová, C zelená, D mátová).

## Technicky

Jeden statický soubor `index.html` bez build kroku: HTML, CSS a JavaScript v jednom souboru, fonty Instrument Sans a JetBrains Mono z Google Fonts. Navigace funguje přes `#kotvy` (např. `#pecujici-cas`), web je responzivní a má světlý i tmavý režim.

Lokálně stačí otevřít `index.html` v prohlížeči. Pro zveřejnění zapněte GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).

## Zdroje

Data a citace jsou uvedeny pod každým grafem. Údaje označené „k ověření“ je třeba před zveřejněním potvrdit v původních zdrojích.
